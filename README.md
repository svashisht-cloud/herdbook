# Herdbook

Simulated ROS 2 robots stream telemetry to a cloud backend over MQTT; faults upload MCAP clips to object storage; a dashboard shows the fleet live. See [ARCHITECTURE.md](ARCHITECTURE.md). The full write-up comes in Step 7.
